# Porsche 360º Scroll-Driven Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a cinematic 360-degree vehicle rotation Hero section using HTML5 `<canvas>` and 121 sequentially numbered studio frames of the Porsche 911 GT3 RS, synchronized with page scroll via GSAP ScrollTrigger (`pin: true`, `scrub: 0.5`), accompanied by smooth asynchronous preloading and dynamic informational overlay cards corresponding to key rotation angles (front, side, rear, 360 overview).

**Architecture:** 
- A dedicated client component `Porsche360Hero.tsx` pinned via GSAP ScrollTrigger over a `400vh` scroll track.
- High-performance HTML5 `<canvas>` rendering engine with device-pixel-ratio scaling, aspect ratio preservation (1284x716 source), and dynamic background matching (`#000407`).
- Parallel asynchronous image preloader caching all 121 frames into memory before activating scrub, showing a sleek minimalist loading bar.
- Animated narrative overlays triggered at designated rotation progress intervals (Front, Profile, Rear, and Final CTA).
- Integration into `ClientDealershipPage.tsx` replacing/enhancing the static hero.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, GSAP 3 + ScrollTrigger, Lenis Smooth Scroll, Lucide React.

**Spec:** The prompt requirements provided in the user request:
- Frames in `/porsche/` (`frame_001.jpg` to `frame_121.jpg`).
- HTML5 `<canvas>` responsive to viewport.
- Async preloader eliminating frame flicker.
- GSAP ScrollTrigger (`pin: true`, `scrub: 0.5`).
- Multi-stage content overlay (frente, perfil, traseira, CTA).

## Global Constraints

- Background color: `#000407` (exact background sampled from the 360 frames) blending into `#07080a`.
- Frame count: 121 frames (`frame_001.jpg` to `frame_121.jpg` in `/porsche/`).
- Zero `any` in TypeScript; strictly typed interfaces.
- Cleanup: all GSAP animations and ScrollTrigger instances must be properly reverted/destroyed on unmount (`useGSAP` with scope or `ctx.revert()`).
- Responsive: canvas and text overlays must adapt gracefully from mobile (360px) to ultra-wide (1920px+).
- Respect `prefers-reduced-motion: reduce`.

## Review Focus

1. Canvas image tearing or distortion when resized or on high-DPI screens.
2. Race condition where user scrolls before all 121 frames are loaded.
3. Smooth synchronization between Lenis ticker and ScrollTrigger scrub.
4. Memory leaks from un-disposed canvas contexts or detached image references.
5. Text overlay readability over different car angles.
